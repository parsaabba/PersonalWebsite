Day 11

Pointers in Go

Understanding memory addresses, referencing vs. dereferencing, and why Go uses pointers for performance and modification.

1 What is a Pointer?

A pointer stores the memory address of a variable instead of the value itself.

Address Operator (&)

x := 10
fmt.Println(&x) // 0xc0000140a8

Dereferencing (*)

p := &x
fmt.Println(*p) // 10

2 Modifying Original Values

By passing a pointer to a function, you can modify the original variable rather than a copy.

func update(a *int) {
    *a = 100
}

x := 10
update(&x)
fmt.Println(x) // 100

3 Pointers with Structs

Go automatically handles dereferencing for struct fields, making the syntax very clean.

type Student struct { GPA float64 }

func updateGPA(s *Student) {
    s.GPA = 8.5 // Same as (*s).GPA
}
